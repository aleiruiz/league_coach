# Harness vs plain Claude Code on main (6ed6728), 2026-11-13

Patch 26.22 (Data Dragon 16.22.1, en_US). Both sides used the CLI's default model.

- **Harness:** the app's real prompts, generated by compiling main and calling the Rust functions from a local test driver (`analysis_prompt`, `card_prompt`, `validate`/`missing` with the app's one fix round, `review_prompt`/`parse_report`, `tierlist::prompt`/`clean_list`, and the `prompts::coach` system prompt). It also used the app's exact CLI flags: WebSearch only, `dontAsk`, no user settings.
- **Plain:** Claude Code with WebSearch and WebFetch, no system prompt, and the same question.
- **Judge:** the existing judge (`run_eval.judge_pair`, `rubric.md` / `rubric_history.md`), both A/B orders. Scores are the substance score `fondo` (0-5); W/T/L uses a ±0.25 threshold.
- **Environment:** the sandbox proxy blocks u.gg, op.gg, Mobalytics, Lolalytics, METAsrc and League of Graphs for page fetches, but search works. The same applies to both sides.
- **Codex:** not installed in this environment, so it was not run.

## Why
- **The card loses because it never sees the question.** Situational questions like "when do I buy anti-heal?" or "it's minute 18, what do I change?" get a full pre-game card. The judge's context score is −1.0 and format is −0.8.
  - When the same question goes to the Ask panel with the card as context, which is the app's real flow, the result is a tie.
  - The card itself has 0 invalid names on the first try. Plain has no invalid names either, but uses outdated terms twice ("mythic", Eyeball Collection).
- **Matchup wins on actionability (+1.1) and honesty (+0.7).** The live-patch line stops outdated items, there is one decisive setup, and it doesn't send the player to "check u.gg".
- **The review wins on precision (+1.6).** Every number and G ref checks out. Plain uses outside benchmarks (e.g. "75-80 CS@10"), gets some figures slightly wrong and gives no measurable targets.
- **The tier list doesn't work on main.** It only sees search snippets, so after cleaning it never reaches `MIN_ENTRIES` = 8, and all 6 runs were refused. #34 (fetching the page on the stat sites) is needed and has to be tested on a machine that can reach those sites.
